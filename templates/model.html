From raw listing to estimate

  1. Clean the listings. Remove duplicates, turn “2 BHK” into 2 and “1100 - 1300” sq.ft into 1,200, convert other units, and drop impossible values such as 6 bedrooms in 600 sq.ft.

  2. Remove price outliers per locality. A listing whose rate per sq.ft is far from the rest of its locality (outside 1.5 × IQR) is left out.

  3. Prepare the features. Fill missing values, take the log of the area, scale the numbers and one-hot encode location and area type.

  4. Learn log(price). Prices are skewed, so the model predicts the log of the price and converts it back.

  5. Pick the best model. Six models are compared with 5-fold cross-validation, the best is tuned with grid search when it has settings to tune.

  6. Test on unseen houses. The final score comes from the 20% of houses kept aside from the start.

Use the API

Send house details as JSON and get the estimate back. Only location, total_sqft, bhk and bath are required.

curl

curl -X POST {{ host_url }}/api/predict \
  -H "Content-Type: application/json" \
  -d '{"location": "Whitefield", "total_sqft": 1200,
       "bhk": 2, "bath": 2, "balcony": 1,
       "area_type": "Super built-up Area",
       "ready_to_move": true}'

Python

import requests

house = {"location": "Whitefield", "total_sqft": 1200,
         "bhk": 2, "bath": 2}
r = requests.post("{{ host_url }}/api/predict", json=house)
print(r.json()["price_text"])

About the data

The model uses the columns of the public Kaggle “Bengaluru House Price Data” set: area type, availability, location, size, society, total area, bathrooms, balconies and price (in lakh). The repository ships with a synthetic sample in that format so it runs offline. To use the real listings, replace data/Bengaluru_House_Data.csv with the Kaggle file and run python src/train.py.
